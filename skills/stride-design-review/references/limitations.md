# Limitations: what this skill does not enforce

This is a plain Agent Skill. It runs on any host that loads skills, and in exchange it gives up the controls an agent harness
can enforce (per-role tool allowlists, read denies, write confinement, hooks, subagent profiles, model pinning, an attestation of
the host's isolation). What the **scripts** enforce is still enforced. What the **harness** used to enforce is now convention,
and a model or a hostile corpus can ignore a convention.

The table says, row by row, what holds and what does not. A reader of any report from this skill should be able to see what was
and was not protected for that run. Nothing here is hidden or softened. The hardened, harness-specific variants still exist in the
frozen source repositories: twelve agent profiles with per-role tool allowlists and read-only profiles,
an installer, a model pin tool and a profile validator.

## How to read "Strength now"

| Label | Meaning |
|---|---|
| **kept** | enforced by a script on every host |
| **same as before** | it was always a prose rule, and still is |
| **weakened, recorded** | enforced less strongly than before, and the evidence level is written into the run output |
| **detect-only** | a violation can be noticed after the fact, not prevented |
| **host-dependent, recorded** | depends on what the host provides; the result is recorded per unit |
| **lost** | nothing enforces it any more; it is a convention |

## What every run summary must say

`stride_run.py summary` (and `finalize`, and the `done` of the narrower modes) end with a SAY THIS block, and the final report's
chapter 1 carries the dispatch block, the disclosure, the limitations line and any reply note from `summary` (copying them is a
convention: no validator reads that chapter for them). In this order:

1. the dispatch mode of the run (`subagent` or `inline`) and why it was chosen, the isolation method as recorded, the dispatch
   record unit by unit with the models when recorded, and, for any unit that ran inline or was never recorded, that independence
   is weaker or unknown;
2. the disclosure line: for an inline run, the reduced-independence statement of `inline-mode.md` and that the inline discipline
   is a convention; for a run with subagents, that a subagent's fresh context is the host's claim and is not verified here;
3. any reply note (a reply whose fence was never closed and was read as far as it went);
4. the approval gates: this skill has none;
5. the sentence "Not enforced on a plain skill install: see" and the absolute path of this file, so the reader can find it.

## Known limits of the analysis

These are about what the method can know, not about what a host enforces. They hold on every host, they were true of the
harness-specific originals too, and nothing in this skill claims to have closed them.

- **The corpus is the system.** Everything is judged against the supplied documents, never the implementation. Silence in the
  documents is a missing-information item or a documentation gap, not proof that a control does not exist. The review
  establishes design-review closure, not implementation or operational effectiveness.
- **Exact quotes prove presence, not interpretation.** `validate_report.py` checks that a quote occurs byte for byte in a
  declared source. It cannot check that the proposition follows from it.
- **Machine schemas prevent malformed artifacts, not flawed security judgment.** Threat discovery and adjudication are model
  tasks and vary between runs. No claim of deterministic extraction is made; only traversal and ID assignment are deterministic
  given identical extracted records. Publish measured run-to-run agreement when you have it.
- **Non-text sources.** Plain text, Markdown, JSON, YAML, CSV and similar sources are read natively. PDF, office, spreadsheet,
  diagram and scanned sources need an extraction map that states method, fidelity, page mapping and diagram interpretability, and
  the skill extracts nothing itself. An unreadable or uninterpretable material diagram creates a missing-information item and a
  limitation, never silent coverage.
- **Context limits.** A corpus that does not fit one context is read in deterministic chunks with per-source extent records. A
  partial extent can support a local proposition, never a corpus-wide absence.
- **The sweep is bounded.** It adds at most `min(15, ceil(20% of the Stage 1 and Stage 2 issues))` candidates, once, and the queue
  never takes later discoveries. It cannot find what the documents do not describe.
- **Impact-only severity.** Severity measures supported consequence, never probability or attacker effort. A missing fact that could
  raise the impact is kept as a conditional ceiling with its gating missing-information item, and the decision rule turns such a
  Critical or High finding into `Insufficient documentation`.
- **Model self-report.** Models, runtime and reasoning effort in the manifest are what the coordinator and the host said. A host
  can route or fall back to another model without telling you.
- **Delta mode** re-reviews changed sources and their dependent paths against a baseline report; it never implies a full reread.
- **The queue is a batch.** Nothing locks the run folder: give each run its own folder, and do not run two coordinators on one.

## How much to trust the verification

A verifier that ran in a fresh host subagent is independent of the stages and of the other verifiers only as far as the host's
subagent boundary is. A verifier that ran inline was confirmed by the same reader that produced the finding: its `Confirmed` is
weaker evidence than a `Confirmed` from a fresh context, and `False positive` requires positive contradiction either way. For a
decision that matters, prefer a host whose subagents start from a fresh context, read the dispatch record, and have a person read
the quotes the verifiers cited.

## When to update this file

Whenever a script gains or loses a check that this table says is **kept**, or a host feature changes what can be enforced. A row may
only get stronger because a script now enforces it, never because a convention was reworded.
